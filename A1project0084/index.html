Reflection

ปัญหาที่เจอ

ปัญหาเรื่องการจัดข้อความให้อยู่กึ่งกลางขนาดข้อความตำแหน่งของข้อความให้ดูดี ต้องแก้ไปที่ละส่วนแล้วเปิดดูในเบราว์เซอร์ควบกัน

สิ่งที่เข้าใจมากขึ้น

เข้าใจมากขึ้นว่าการตั้งชื่อไฟล์และจัดโครงสร้างโฟลเดอร์ให้เป็นระบบ เพราะถ้า path ของไฟล์ผิดแม้แต่นิดเดียว รูปภาพหรือ CSS ก็จะไม่แสดงผลทันที เว็บไซต์หน้าเดียวก็ออกแบบให้ดูเป็นระเบียบและใช้งานง่ายได้ถ้าวางโครงสร้างเนื้อหาให้ชัดเจนตั้งแต่แรก

ถ้าทำต่ออยากเพิ่มอะไร

อยากเพิ่มเมนูที่ใช้งานง่ายขึ้นปุ่มเลื่อนกลับขึ้นด้านบนหน้าเว็บค่อนข้างยาวและอาจทำให้ผู้เข้าชมหาข้อมูลที่ต้องการได้ไม่สะดวก อยากปรับปรุงเรื่องการเลือกใช้สีและฟอนต์ให้มีเอกลักษณ์และดูเป็นมืออาชีพมากขึ้น เพราะตอนนี้ยังเน้นเรื่องโครงสร้างเป็นหลัก ยังไม่ได้ใส่ใจเรื่องความสวยงามมากนักอยากเพิ่มส่วนแสดงผลงานหรือโปรเจกต์อื่น ๆ ที่เคยทำ
